# Configurer un Agent d'Extraction

## Formats des documents traités par un Agent d'extraction {#formats-des-documents-traites-par-un-agent-dextraction}

Un Agent d'extraction accepte les PDF (`.pdf`), les images JPEG (`.jpg`, `.jpeg`), PNG (`.png`) et TIFF (`.tif`, `.tiff`), les fichiers texte (`.txt`, `.html`) et les documents bureautiques (`.doc`, `.docx`, `.docm`, `.ppt`, `.pptx`, `.xlsm`, `.xlsx`, `.odt`, `.ods`, `.odp`, `.rtf`). Les PDF et TIFF peuvent comporter plusieurs pages.

Le type est déterminé à partir du contenu du fichier, et non de sa seule extension ou du type MIME déclaré lors de l'envoi. Un fichier renommé avec une extension acceptée ne devient pas pour autant un document exploitable. Ce contrat vaut pour le [chargement de documents en validation](../valider-un-agent/charger-des-documents-en-validation.md) comme pour le module d'extraction d'un Workflow. Les [formats des Agents de classification](../../classification/configurer-un-agent-de-classification.md#formats-des-documents-traites-par-un-agent-de-classification) ne sont pas identiques.
