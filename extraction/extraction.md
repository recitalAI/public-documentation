# 🎯 Extraction

L'objectif d'un projet d'extraction reciTAL est de configurer un Agent capable d'extraire les informations dont vous avez besoin au sein d'un type de document. Ces informations peuvent être des champs simples (texte, dates, montants) comme des structures plus complexes (tableaux, sections répétées).

Un projet d'extraction reciTAL est constitué de plusieurs étapes importantes que nous verrons en détail les unes après les autres.

  * [Annoter un Dataset](entrainer-un-modele-dextraction/annoter-un-dataset.md)
  * [Entrainer un modèle](entrainer-un-modele-dextraction/entrainer-un-modele.md)
* [Configurer un Agent d'extraction](configurer-un-agent-dextraction/)

  * [Configurer les paramètres d'un Agent](configurer-un-agent-dextraction/configurer-les-parametres-dun-agent.md)
* [Valider un Agent](valider-un-agent/valider-un-agent.md)
