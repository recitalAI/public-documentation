# Créer un Doc Type

# Créer les data points

Une fois votre Doc Type créé vous pouvez aussi choisir de lui ajouter manuellement des data points. Il y a deux méthodes d’extraction à partir des data point, soit à partir d’un modèle, soit à partir d’un ensemble de règles.

Il faut d’abord créer un nouveau data point et le nommer avant de choisir l’une des deux méthodes.

![*Data point - création d’un nouveau data point*](Cre%CC%81er%20un%20Doc%20Type%208a89c413306c4c5b898548dc1c8b9bde/dp1.png)

*Data point - création d’un nouveau data point*

Cliquez sur Single Data Point.

![*Data point - nommage d’un nouveau data point*](Cre%CC%81er%20un%20Doc%20Type%208a89c413306c4c5b898548dc1c8b9bde/dp2.png)

*Data point - nommage d’un nouveau data point*

Puis nommez-le.

# Modèle ou règles

Pour créer un data point à partir d’un modèle, cliquez sur l’onglet “modèle” puis choisissez un modèle et ensuite un de ses labels.

Cliquez ensuite sur le bouton SAVE.

Vous verrez ensuite s’afficher à droite les valeurs extraite sur les documents de validation.

![*Data point - création à partir d’un modèle*](Cre%CC%81er%20un%20Doc%20Type%208a89c413306c4c5b898548dc1c8b9bde/dp_model.png)

*Data point - création à partir d’un modèle*

Vous pouvez aussi choisir d’ajouter un data point défini par un ensemble de règles.

Dans l’exemple suivant nous allons créer un data point qui sera une entité nommée de type MONTANT située n’importe où dans le document et qui sera la valeur de la clé TOTAL HT.

![*Data point - création à partir d’un ensemble de règles*](Cre%CC%81er%20un%20Doc%20Type%208a89c413306c4c5b898548dc1c8b9bde/dp_rules.png)

*Data point - création à partir d’un ensemble de règles*

On peut voir qu’il y a eu un match, la valeur est affichée en bas de l’écran ainsi que directement sur le document à droite.
