# Paramètres

L’écran Paramètres permet de modifier les paramètres suivants :

- *Utiliser Google OCR* : coché par défaut. Décocher l’option activera l’OCR Tesseract.
- *URL de callback* : L’URL de callback peut se paramétrer à cet endroit. Il s’agit de l’URL sur laquelle seront renvoyées les informations appelées via l’utilisation des routes API.
- *Langue* : permet de mettre à jour la langue de l’organisation.
- *Documentation de l’API* : la documentation complète des API Extract est disponible via le bouton.
