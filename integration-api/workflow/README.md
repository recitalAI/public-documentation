# Workflow

L'API Workflow permet de piloter vos workflows par programmation : envoyer des documents pour traitement et suivre les jobs créés.

* [Envoyer des documents dans un workflow](envoyer-des-documents-dans-un-workflow.md) — créer un job et charger un document via l'API.

L'authentification est décrite dans [Authentification](../authentification.md). Pour la structure des données renvoyées en fin de traitement, voir [Workflow callback](../structures-de-resultats.md).
