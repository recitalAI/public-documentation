# Métriques d'évaluation

**Précision** : parmi les champs extraits par le modèle, proportion de ceux qui sont corrects. Une précision élevée signifie que les valeurs extraites sont fiables.

**Rappel** : Mesure la capacité du modèle à ne pas rater des informations. Un rappel élevé signifie que si un champ est dans un document, le modèle va probablement bien l'extraire.

**F1-Score** : combinaison de la précision et du rappel. Il offre un compromis entre les deux ; selon le cas d'usage, on peut privilégier la précision (limiter les erreurs) ou le rappel (ne rien manquer).
