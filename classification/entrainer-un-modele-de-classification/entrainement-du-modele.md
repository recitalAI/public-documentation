# Entrainement du modèle

Rendez-vous dans l'onglet Modèle - Classification.

<figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

Cliquez sur "Créer un modèle de classification/split".

<figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>

Sélectionnez ensuite les datasets (classes) que vous souhaitez utiliser pour votre modèle de classification, puis appuyez sur "Continuer".

<figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>

Donnez un nom à votre modèle de classification.

<figure><img src="../../.gitbook/assets/image (31).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Veillez à ce que l'option **"Ne se reposer que sur le contenu"** soit bien activée. Si elle ne l'est pas, le modèle se reposera (en plus du contenu) sur le nom du fichier.
{% endhint %}

Continuez, puis lancez l'entraînement.

Une fois l'entraînement terminé, le modèle apparaît dans la liste des modèles.
