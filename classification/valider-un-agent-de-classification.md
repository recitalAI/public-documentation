# Valider un Agent de classification

Un [Agent de classification](configurer-un-agent-de-classification.md) applique un modèle pour attribuer des catégories aux documents. Avant de l'utiliser dans un Workflow, vous pouvez examiner les documents et les résultats de classification de cet Agent.

## Accéder à l'onglet Documents

1. Dans **Agents**, ouvrez l'onglet **Classification**.
2. Ouvrez l'Agent de classification concerné.
3. Sélectionnez l'onglet **Documents**.

## À quoi correspond « Télécharger un bundle » ?

L'action **Télécharger un bundle** est présente dans l'onglet **Documents** d'un Agent de classification.

{% hint style="warning" %}
**Documentation en cours de vérification — ne pas publier cette page en l'état.** Le contenu exact du bundle, l'action déclenchée, ses prérequis et son usage doivent être vérifiés dans le code de la version de production avant de compléter cette section. Il ne faut pas assimiler ce libellé à un import de fichiers, ni en déduire un format ZIP ou un lien avec `is_bundle`, sans vérification.
{% endhint %}
