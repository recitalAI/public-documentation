# Version 25.10.x (30/10/2025)

### Version 25.10.12 (30/10/2025)

#### Extraction

* Correction d'un bug avec la fonctionnalité de remplacement de modèle dans les agents d'extraction.

#### Écran de review d'extraction

* Un groupe de datapoint entier peut maintenant être entièrement supprimé.
* Correctif pour empêcher la review d'un même document par 2 personnes en simultané.

#### Workflows

* Corrections de bugs lors de l'édition d'un workflow.
* Les jobs "done" de plus de 15 jours seront automatiquement supprimés. Les autres seront supprimé au bout de 30 jours.

#### Autre

* Les tokens de service API peuvent être étiquetés, et on peut les délier de l'utilisateur qui l'a généré.&#x20;
* Une organisation entière peut être exportée / importée.
* Correction de bug dû à la pagination de différents tableaux dans l'interface.
* Diverses améliorations mineures et correction de bugs.
