# 📖 Suite reciTAL - Documentation

## À propos de reciTAL

Première solution <mark style="color:purple;">**LAD/RAD labellisée Deep Tech**</mark>, la plateforme [<mark style="color:purple;">**reciTAL**</mark> ](https://recital.ai)assure la capture, le typage et la recherche, pour <mark style="color:purple;">**tous les types de documents et de mails**</mark>.

## Solution multilingue

reciTAL traite les documents et les mails dans plusieurs langues : il reconnaît et extrait les données indépendamment de la langue (français, anglais et autres langues).

## No code / Low-code

La plateforme se configure et s'utilise sans compétences en programmation. Les workflows se construisent depuis l'interface ; le low-code permet d'ajouter des traitements spécifiques en Python lorsque c'est nécessaire.

## Exemples de cas d'usage

* **Traitement de factures** : Automatisation de la capture et de l'extraction des données des factures pour accélérer le traitement comptable.
* **Gestion des demandes client** : Classification et extraction des informations des mails clients pour une gestion rapide et efficace des demandes.
